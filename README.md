# 플랜두씨 다이어리 (과제 6)

계획(Plan) → 실제로 한 일(Do) → 돌아보기(See)를 하나로 잇는 다이어리. 로그인 없음(잠그는 일은 7번 과제). 자료는 SQLite 계열 DB(`@libsql/client`)에 저장됩니다. 로컬에서는 파일, 배포(Vercel)에서는 Turso입니다.

## 실행

```bash
npm start          # http://localhost:3000  (Node 22 이상, 처음 한 번 `npm install`)
npm test           # API 41개 검사 (임시 DB 사용, 실제 자료에 영향 없음)
```

로컬 환경변수: `PORT`(기본 3000), `DB_PATH`(로컬 개발·테스트 전용, 기본 `data/pds.db`). `DB_PATH`는 Turso를 쓰지 않을 때만 의미가 있고, Vercel에서는 디스크가 유지되지 않으므로 아래 '배포' 절의 Turso를 쓰세요.

## 파일

| 파일 | 내용 |
|---|---|
| `lib/server.js` | API, DB 스키마(libSQL), 지연·집계 규칙, 보안 헤더 |
| `public/` | 화면 (`app.js`는 사용자 글자를 `textContent`로만 넣음) |
| `contracts/pds-schema-v2.json` | 표·항목·관계·날짜 규칙 |
| `docs/design-references.md` | 디자인 참고 서비스 34곳 실측 기록 (앱 안 `/references.html`에도 있음) |
| `tests/api.test.js` | 통과 기준 자동 검사 |
| `api/index.js`, `vercel.json` | Vercel 서버리스 진입점과 라우팅 설정 |

디자인 = 종이와 잉크 + 단계 인덱스(PLAN/DO/SEE), 대비 4.5:1 이상.

## 지연·집계 규칙
- 오늘은 서울(Asia/Seoul) 기준. 날짜는 `YYYY-MM-DD`, 시각은 UTC ISO로 저장하고 화면에서 서울 시간으로 보여 줌.
- 지연 = 완료되지 않았고 마감일이 오늘보다 앞선 할 일 (완료한 일은 세지 않음).
- 막힘 = 막힌 이유가 적힌 실행 기록이 하나라도 있는 할 일. 차이 = 실제 − 예상 (기록 없으면 0). 단위는 분.

## 제출 전에 직접 할 일
1. **내 자료 넣기.** 이 앱에는 예시 데이터가 없습니다(남의 예시가 아니라 내 것으로 채워야 하는 과제). 계획 1개+, 할 일 5개+, 실행 기록 3개+를 직접 입력하세요.
2. 결과물·소스 URL이 새 시크릿 창에서 열리는지 확인.
3. 제출문의 "AI에게 맡긴 일 / 내가 직접 판단한 일 / AI 제안을 따르지 않은 일"은 본인이 겪은 대로 적으세요. 초안(AI가 한 일): 서버·화면 구현, 스키마 계약, 디자인 참고 34곳 조사와 팔레트 정리, 자동 테스트.

## 배포(Vercel + Turso)
Vercel 함수는 디스크가 유지되지 않으므로 자료는 Turso(libSQL)에 저장합니다.

1. Turso에서 데이터베이스를 만들고 접속 주소와 인증 토큰을 발급합니다. (값은 화면·코드·README·저장소 어디에도 적지 마세요.)
2. Vercel Project Settings → Environment Variables에 다음 두 이름으로 등록합니다.
   - `TURSO_DATABASE_URL`: Turso 데이터베이스 접속 주소
   - `TURSO_AUTH_TOKEN`: Turso 인증 토큰
3. 배포하면 `public/`은 Vercel이 정적으로 서빙하고, `/api/*`와 `/contracts/*`는 `api/index.js` 함수(`lib/server.js`의 handler)가 처리합니다. 표는 첫 요청(콜드 스타트) 때 없으면 자동으로 만들어집니다(`CREATE ... IF NOT EXISTS`).
4. 로컬 폴백: `TURSO_DATABASE_URL`이 없으면 로컬 파일(`DB_PATH` 또는 `data/pds.db`)을 씁니다. 개발·테스트용이며 `npm test`도 임시 파일 DB로 돌아 원격에 접속하지 않습니다.

배포 후 확인: `https://<배포 주소>/api/meta`가 200과 JSON을 돌려주는지, `/` 화면이 뜨는지, `/contracts/pds-schema-v2.json`이 열리는지 봅니다. 계획을 하나 만들고 새로고침·재배포 뒤에도 남아 있으면 Turso 저장이 정상입니다. 자료를 파일로 받으려면 화면의 '내 자료 파일로 내보내기'를 쓰면 됩니다.
